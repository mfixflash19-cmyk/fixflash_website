# FixFlasH Website — Design Update

This update edits the existing FixFlasH website to more closely match the requested dark navy, neon blue and orange preview. It includes the circular logo, desktop/mobile responsive layout, navigation, four service categories, wallet demo card, demo order tracking, and demo deposit request form.

## Open the website
1. Extract this ZIP file.
2. Open `index.html` in Chrome or Edge.

## Important
This is still a front-end prototype. Login/Register are visual placeholders; orders and deposit requests are stored only in the current page session. There is no secure backend, database, customer authentication, actual wallet balance, or blockchain verification. Do not use it to accept real customer data or payments until those systems are implemented securely.

Edit the service names and demo prices in `app.js`.
